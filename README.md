# Maze Generator & Solver

Генератор и решатель лабиринтов на Java с поддержкой нескольких алгоритмов.

## Содержание

- [Использование](#использование)
- [Требования](#требования)

## Использование

### Интерактивный режим

**Главное меню:**
- **1** - Сгенерировать лабиринт
- **2** - Справка
- **0** - Выход

### Генерация лабиринта

**Доступные алгоритмы:**
1. **DFS** (Depth-First Search) - рекурсивный поиск в глубину
2. **Prim True** - классический алгоритм Прима
3. **Prim Simplified** - упрощённая версия Прима
4. **Prim Modified** - модифицированная версия Прима

**Пример:**

```
Выберите алгоритм (1-4): 1
Введите ширину лабиринта: 15
Введите высоту лабиринта: 15
```

### Решение лабиринта

**Доступные алгоритмы:**
1. **Dijkstra** - гарантирует кратчайший путь
2. **A*** - эвристический поиск с манхэттенской дистанцией

**Источник лабиринта:**
- Сгенерированный ранее

**Пример:**

```
Введите начальную точку (формат x,y): 1,1
Введите конечную точку (формат x,y): 13,13
```

Начало координат в левом верхнем углу, при движении вниз растёт y, вправо - x

### CLI режим (Picocli)

```bash
# Генерация и сохранение
java -jar app.jar generate -a dfs -w 10 -h 10 -o maze.txt

# Решение из файла
java -jar app.jar solve -a dijkstra -f maze.txt -s 1,1 -e 9,9 -o solution.txt

# Вывод в консоль
java -jar app.jar generate -a prim -w 5 -h 5
```

## Требования

### Функциональные

- ✅ Генерация лабиринтов несколькими алгоритмами
- ✅ Решение лабиринтов методами Dijkstra и A*
- ✅ Два режима интерфейса: интерактивный и CLI
- ✅ Отображение пути через лабиринт при его наличии в консоль.
- ✅ Сохранение решения в файл.

### Технические

- Java 11+
- Maven для сборки
- JUnit 5 для тестирования
- SLF4J для логирования
- Picocli для CLI

## Обозначения в лабиринте

```
# — стена
(пробел) — проход
O — начальная точка
X — конечная точка
. — найденный путь решения
```
